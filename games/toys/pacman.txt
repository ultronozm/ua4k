;; PACMAN.  Register-carried ghost floors, a one-way house door, a
;; four-phase speed clock, and capture variables throughout.
;;
;; == Register ledger =====================================================
;; All rows are 28 wide and rectangular.  Hidden rows start with `%`.
;;
;;   row A  %{-}-^1...     {  queued Pacman heading   (eswn, `-` none)
;;                         }  current Pacman heading  (eswn, `-` none)
;;                         ^  speed phase             (1234, cycles per tick)
;;   row B  %(w)n[n]n...   (  R heading   )  K heading
;;                         [  I heading   ]  C heading
;;   row C  %!1-!2-...     !1 !2 !3 !4  carried floor under R K I C
;;   row D  %<1>0&0+--~0... < mode        > release counter
;;                         & eat chain    + pause field
;;                         ~ frightened timer
;;
;; Actors: P pacman; R K I C normal ghosts; q x z b the same four
;; frightened; h j l unreleased K I C; X dead Pacman.  Visible HUD strings
;; avoid q x z b and the register anchor `!`.
;;
;; Tick order: clock_phase | pac_turn | pac_move | ghost_choose |
;; ghost_move | fright_move | state_clock.  Pacman resolves before ghosts,
;; so an energizer affects ghosts on the same tick.
;;
;; Collisions: normal-ghost contact in either direction turns Pacman's
;; cell into `X`.  Eating a frightened ghost scores the chain, consumes
;; its carried floor, and respawns it in the house.  Carried tiles
;; survive every transition; completion is direct (GOAL P, VOIDs on `.`
;; `O` `X` -- carried floors in the register rows block the goal too).

;; Frightened mode.  Energizers reverse all ghosts, reset the eat chain,

  K x

  I z

  C b

  ~? ~9

  &? &0

  CALL reverse_all

;; Round reset: after the death

;; -----------------------------------------------------------------------
;; Steering.  R directly pursues, K keys off Pacman's heading, I alternates
;; axes randomly, and C retreats when nearby.  Aim commands reject an
;; immediate reversal; the physical mover still chooses a legal fallback.

;; Feasible tries: a try succeeds only when the ghost is present,
;; the destination is walkable for a chasing ghost, and the current
;; register (the last successful travel direction) is not the reverse of
;; the tried direction.  An infeasible or reversing preference fails so
;; the personality's next ordered preference runs; the mover keeps its
;; own last-resort reversal for dead ends.

ROTATE_CMDS try_r eswn
 FOR j esn
  ATOMIC 1 chase
   (j (j [norotate]

   R1 R1

   (? (e [norotate]

ROTATE_CMDS try_k eswn
 FOR j esn
  ATOMIC 1 chase
   )j )j [norotate]

   K1 K1

   )? )e [norotate]

ROTATE_CMDS try_i eswn
 FOR j esn
  ATOMIC 1 chase
   [j [j [norotate]

   I1 I1

   [? [e [norotate]

ROTATE_CMDS try_c eswn
 FOR j esn
  ATOMIC 1 chase
   ]j ]j [norotate]

   C1 C1

   ]? ]e [norotate]
